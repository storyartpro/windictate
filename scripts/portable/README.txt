WinDictate — портативная версия
===============================

Что это
-------
Приложение «Диктовка» в одном zip-архиве: распаковываете в любую папку и запускаете
WinDictate.exe. Ничего не устанавливается в систему, настройки, история и логи
хранятся внутри этой же папки (data\).

Первый запуск
-------------
1. Распакуйте архив в папку, куда у вас есть права записи (например,
   C:\Users\<вы>\Apps\WinDictate, не в Program Files).
2. Запустите bootstrap.cmd — он один раз создаст окружение runtime\ и скачает
   Python-зависимости. Нужен uv (https://docs.astral.sh/uv/); при наличии
   NVIDIA GPU добавятся CUDA-библиотеки.
   WinDictate.exe сделает это сам при первом запуске, если runtime\ ещё нет.
3. Дальше просто запускайте WinDictate.exe (или ярлык на него).

Горячие клавиши
---------------
Ctrl+Alt+Space — начать/остановить диктовку.
Ctrl+Alt+S     — настройки.
Оба сочетания меняются в настройках; при первом запуске используются значения
по умолчанию.

Команды WinDictate.exe
----------------------
WinDictate.exe             запуск (если уже запущено — предложит перезапуск)
WinDictate.exe --start     запуск, если не запущено
WinDictate.exe --restart   перезапуск
WinDictate.exe --stop      остановить
WinDictate.exe --settings  открыть настройки
WinDictate.exe --open      открыть окно диктовки
WinDictate.exe --status    код 0 — работает, 10 — остановлено
WinDictate.exe --version   версия

Что внутри
----------
WinDictate.exe   — управляющий exe (запуск/остановка/настройки)
portable.flag    — маркер портативного режима
bootstrap.cmd    — первичная настройка окружения
app\             — код приложения и ресурсы
runtime\         — Python 3.11 и зависимости (создаётся bootstrap.cmd)
data\            — settings.json, history.json, logs\ (создаётся при запуске)

Модели распознавания
--------------------
Модели faster-whisper скачиваются при первом использовании в общий кэш
(%USERPROFILE%\.cache\huggingface) — так они не дублируются между копиями.
Для полностью автономной папки скопируйте этот кэш вручную.

Важно
-----
- Не запускайте одновременно установленную и портативную версии: у обеих общая
  глобальная горячая клавиша, и вторая не сможет её занять.
- Портативную версию можно удалить, просто удалив папку.
- Для автозапуска с Windows: создайте ярлык на WinDictate.exe в
  shell:startup (Win+R) с параметром --autostart.
